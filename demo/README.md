# KnowFlow V2 Teaching Demo

This directory contains a browseable condensed reference for the V2 request-planning architecture. The complete multi-file learning package is published as a branch artifact ZIP by the V2 update.

Core concepts to inspect:

1. `demo_runner.py`: six scenario CLI/trace contract;
2. `knowflow_v2_demo.py`: self-contained Intent/Task-DAG compiler reference;
3. repository V2 docs: fixed Coordinator Graph and Thread/Turn/Run semantics.

The production intent is **not** to keep the monolithic reference file. The downloadable learning package splits the same concepts into focused modules (`intents/`, `execution/`, `conversation/`, `workflows/`, `scenarios/`).
